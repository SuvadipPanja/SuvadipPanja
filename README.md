### 👋 About me

I design, build and ship complete products on my own — from the first plan to the production server.

- 🎙️ Built an **on-prem AI call-quality platform** for a large Indian financial-services company: every collections call is transcribed, translated, scored and turned into a dashboard, without any data leaving the bank.
- 🧠 Comfortable with the whole AI path: speech recognition, language detection, LLM scoring, GPU sizing and fail-safe pipelines.
- 🛠️ Full stack every day: React front ends, Express APIs, SQL Server / PostgreSQL, Redis, Python services, Docker Compose.
- 🔐 Security-minded: role-based access, signed tokens, licence binding, audit trails, safe rollbacks.
